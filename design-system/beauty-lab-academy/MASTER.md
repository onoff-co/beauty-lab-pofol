# Beauty Lab — 디자인 기준
최종 갱신: 2026-10-23. 이전 자동 생성 Liquid Glass·샴페인 골드·스크롤 스토리텔링 제안은 폐기했습니다.

## 사용자 확정 방향
- 브랜드는 미용학원. 블러시·핑크·버건디 유지.
- MBC/KBS 미용학원처럼 과정 정보, 개강 일정, 상담을 중심으로 구성.
- 내부 페이지의 대형 감성 문구, 영문 장식 라벨, 반복 화살표와 불필요한 배너 금지.
- 전체 교체 허용. 메인뿐 아니라 모든 내부 페이지를 목적에 맞게 설계.
- 스페셜·뷰티스토리 메뉴는 제거 상태 유지.
- 온라인 이론 교육과 학습 관리 포함.

## 토큰
- 본문 #292526, 보조 #686064, 핵심 버튼 #7d304d
- 배경 #ffffff, 보조 배경 #faf8f8, 블러시 #f4e7eb, 핑크 #ead1db
- 본문: 맑은 고딕 / Apple SD Gothic Neo / Arial
- 로고만 Georgia. 읽는 글자는 최소 13px.
- 최대 콘텐츠 폭 1200px. 데스크톱 최소 40px, 태블릿 24px, 모바일 18px 바깥 여백.
- 큰 제목은 메인의 실제 모집 캠페인에만 적용. 내부 제목은 25~28px.
- 정적인 사각형 UI. 그라데이션·글래스·3D·장식 도형 없음.
- 모션은 호버와 컨트롤 피드백에만 사용. 자동 스크롤/등장 애니메이션 없음.

## 레이아웃
- 메뉴: 로고 + 7개 동일 너비 열. 하위 메뉴는 각 상위 메뉴 열에 직접 포함.
- 모바일: 상위 메뉴 버튼 아래에 하위 링크가 펼쳐지는 아코디언.
- 로고: `beauty lab` 뒤의 점을 사용하지 않음. 헤더·푸터 동일.
- 메인: 원본 비율 모집 배너 → 빠른 안내 → 분야별 텍스트 과정 카드 → 작품 → 강사진 → 온라인/지원/패키지 → 일정/공지 → 상담.
- 전문 교육과정: 사진 없이 분야 선택 버튼 4개와 세부 과정 요약 카드 3개. 카드 클릭 시 해당 분야·목적의 상세 경로로 이동.
- 메인 배너: 고정 높이 `cover` 금지. 데스크톱은 원본 비율, 800px 이하에서는 이미지와 문구를 분리하며 `contain`으로 전체 이미지를 표시.
- 과정: 사진·사양 요약 → 목적별 커리큘럼 → 준비물·온라인 연계.
- 일정/공지: 정보 목록과 필터, 검색, 상세 페이지.
- 강의실: 목차 + 학습 본문 + 실제 완료 상태.
- 관리자: 상담·회원·공지의 실제 데모 데이터 조작.

## 진실성
모든 비용·일정·강사·후기는 시연 데이터. 이미지는 기존 생성 시안. 국비지원 승인이나 지원액을 임의로 표시하지 않음.
실제 인증·결제·예약·동영상 시스템을 구현한 것처럼 표시하지 않음.

## 스킬 적용 우선순위
사용자 레퍼런스와 명시 요구가 스킬의 무작위 방향 추첨·대형 타이포·모션 최소 개수보다 우선.
날짜 숫자는 장식 번호가 아니며, 학원 게시판/메뉴 구분선은 요청된 구조를 위해 유지.
tasteskill 검사의 numbering, hairline, body-size, still-page 예외는 이 사유에 한정.
