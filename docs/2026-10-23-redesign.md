## 코드 구조와 결정

`PlatformPage.jsx`는 경로 분기와 메모리 상태를 담당하고, 화면을 `src/pages/`에 분리했다. `components.jsx`는 메뉴·페이지 틀·폼·모달을 공유한다. 기존 미사용 `data.js`는 삭제하고 `academyData.js`로 예시 데이터를 교체했다. 누적 CSS 덮어쓰기를 계속 추가하지 않고 `platform.css`를 교체했다. Git 저장소가 아니므로 삭제한 이전 파일의 Git 복구 이력은 없다.

추가 라우터 의존성 없이 해시 경로를 사용한다. `domain.js`는 과거 한글 경로를 새 경로로 정규화한다. 데이터는 React 메모리 상태에만 저장한다. 포트폴리오에서 실제 개인정보나 인증 토큰을 저장하는 것으로 오해하지 않도록 영구 저장과 가짜 보안 기능은 추가하지 않았다.

## 디자인 검토와 예외

디자인 스킬은 반복 카피 제거, 섹션별 다른 구성, 실제 브라우저 검증에 활용했다. 사용자 레퍼런스가 스킬의 일반적인 편집형 사이트 취향보다 우선한다.

최종 시각 검사 도구는 명시적 예외 4개 적용 후 FAIL 0개, WARN 6개를 보고했다. 예외는 실제 모집 날짜 숫자, 게시판·폼 구분선, 13px 메타데이터/14–16px 본문, 절제된 동작이다. 경고는 글자 크기 종류, 보조 회색 텍스트(검출 대비 5.2:1), 실제 영상 부재, 긴 푸터 고지, 지원 안내 영역 여백, 한국어 모집 제목 분류에 관한 것이다. 정적 스타일 검사에는 드롭다운 그림자와 얇은 구분선 관련 스타일 경고성 FAIL 2개가 남는다. 기능 오류와 구분하며 모두 통과했다고 주장하지 않는다.
