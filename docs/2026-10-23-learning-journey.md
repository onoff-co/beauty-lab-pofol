# 이용 동선·온라인 강의·이미지 개편

## 페이지별 역할

| 진입 | 제공 정보와 다음 행동 |
| --- | --- |
| 교육과정 | 분야 개요 → 목적별 커리큘럼 → 해당 반 확인/상담. 세부 트랙에 개요 배너를 반복하지 않음 |
| 개강일정 | 분야·목적·월·평일/주말 필터 → 14개 반별 상세 → 선택 반이 포함된 상담 접수 |
| 반별 상세 | 날짜·시간·기간·강사·장소·학습 목표·준비물·비용. 전체 과정으로 돌아갈 필요 없이 확인 |
| 온라인 강의 | 과목별 영상 목록·검색 → 공개 강의 플레이어와 동일 분야 목차 → 다음 강의 |
| 나의 강의실 | 담은 분야의 진도와 아직 완료하지 않은 강의로 이어서 학습 |
| 수강료 문의 | 분야별 예시 수강료·재료비 비교 후 문의할 분야 선택 |

일정의 필터는 hash 안의 query에 저장된다. 상세 페이지의 목록 복귀와 평일/주말 탭 이동에도 선택 조건이 유지된다. 로그인 복귀 주소는 내부 online/classroom 경로만 허용한다. 새로고침 시 회원·상담·학습 기록은 사라지는 프런트엔드 데모다.

## 이미지 구성

26장의 신규 생성 사진을 학원소개 1, 캠페인 1, 프로모션 1, 강사 홈 4, 강사 소개 4, 시설 4, 갤러리 4, 작품 상세 4, 수강 이야기 3에 배치했다. 기존 작품 사진 3장은 홈 미리보기에만 남겼다. 과정 사진 5장은 과정 목록 전용, 배너 5장은 분야 개요 전용이다. 수강 이력·일정·트랙마다 같은 사진을 반복하지 않는다.

이미지 프롬프트와 파일 경로: [media-generation-manifest.json](media-generation-manifest.json). 내장 imagegen 사용. 모든 인물·시설·작품은 생성 시안이다.

## 검증 기록

- Node 자동 테스트 20개: 경로 파싱, 잘못된 하위 경로, 필터, 문의 검증, 학습 완료, 콘텐츠/배포 경로, 신규 이미지 26개 파일 및 SHA-256 고유성.
- 필터 조건을 일시적으로 제거하는 변이 테스트에서 해당 회귀 테스트가 실패함을 확인 후 복원.
- 브라우저 주요 39개 화면 × 320/768/1024/1440px = 156회: 가로 넘침, 뷰포트 밖 버튼, 보이는 깨진 이미지 없음.
- 일정 필터 → 반 상세 → 상담 → 완료에 반명·개강일·시간이 유지됨. 목록 복귀 후 필터 유지 확인.
- 공개 영상 8개 모두 YouTube 플레이어 로드 성공. 헤어 총론 1 실제 재생 화면 확인.
- 로그인 후 원래 강의 복귀, 강의실 추가, 자율 학습 완료, 다음 미완료 강의로 이어서 학습 확인.
- 브라우저 로컬 앱 콘솔 오류/경고 없음. 정적 빌드 성공.

검증은 현재 시점의 외부 영상 상태를 보장하며 향후 삭제/임베드 제한 가능성은 있다. 자체 스트리밍, 결제, 실제 인증·출석·수료 시스템은 구현 범위가 아니다.
