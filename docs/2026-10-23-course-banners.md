# 과정별 배너 이미지

내장 image_gen 도구로 신규 생성한 5개 이미지. API/CLI fallback은 사용하지 않음.
과정 대표 및 세부 페이지의 배너에만 적용. 기존 인물·실습 사진은 보존.
원본은 생성 디렉터리에 유지하고 프로젝트 public/assets에 복사함.
이미지에는 문구나 로고를 넣지 않았으며, 실제 학원의 도구를 촬영한 사진이 아닌 생성 시안임.
PC·모바일 모두 object-fit:contain으로 이미지 전체를 표시.
